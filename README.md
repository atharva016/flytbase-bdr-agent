# FlytBase Outbound BDR AI Agent

An autonomous AI-powered sales intelligence pipeline that identifies target accounts, discovers contacts, researches companies, and generates personalized outbound emails for FlytBase's expansion into the Latin American mining sector.

## 🎯 What It Does

Takes a **campaign brief** (target vertical + reference account) and automatically runs a 4-stage pipeline:

1. **Account Identification** — Finds mining companies in Latin America matching the SQM (Sociedad Química y Minera de Chile) ICP profile
2. **Contact Discovery** — Identifies key decision-makers (Head of Operations, VP HSE, Site Directors)
3. **Account Research** — Produces deep research briefs using real public data
4. **Email Generation** — Creates hyper-personalized outbound emails for each contact

## 🚀 Quick Start

### 1. Clone and install
```bash
git clone https://github.com/YOUR_USERNAME/flytbase-bdr-agent.git
cd flytbase-bdr-agent
pip install -r requirements.txt
```

### 2. Set your API key
```bash
# Windows
set GEMINI_API_KEY=your_gemini_api_key_here

# Linux/Mac
export GEMINI_API_KEY=your_gemini_api_key_here
```

### 3. Run the server
```bash
python app.py
```

### 4. Open the dashboard
Navigate to `http://localhost:5000` and click "Run Pipeline"
